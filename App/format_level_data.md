# phases.json フォーマット

- `"data"`は配列 `[]` として、その中に オブジェクト `{}` 形式で各種情報を書き込む
- 各種情報の種類
  - `timeLimit`: 時間指定は文字列にする
  - `similarity`: 類似度条件（ターゲットと同じ特徴パラメータの数が何個あるかを「類似猫」の条件としている）
  - `breedData`: `similar`が「類似猫」を何種類出現させるかの数、`other`が似てない猫の出現数
  - `intervalData`: オブジェクト形式。`period`が1周期の時間、`count`が1周期に出現させる猫の数。
  - `ActionData`
    - `param`: イージング関数を表すパラメータは関数名の先頭に `e_` の接頭辞をつけるようにする。`Rect`型は `"(x, y, w, h)"`のように文字列で書く。
